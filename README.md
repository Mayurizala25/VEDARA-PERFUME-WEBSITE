# VEDARA — Premium Perfume E-Commerce

## Project Overview

VEDARA is a premium perfume e-commerce website focused on modern luxury with subtle Indian fragrance heritage.

The website should feel elegant, cinematic, minimal, premium, and trustworthy. It must be fully responsive across mobile, tablet, laptop, and large desktop screens.

## Brand Identity

- Brand: VEDARA
- Tagline: Wear Your Essence.
- Brand direction: Modern Luxury + Subtle Indian Heritage
- Primary / Champagne: #EFE1CE
- Rose Gold: #B9857C
- Black Cherry: #721D35
- Black Cherry Dark: #42121F
- Near Black: #1C0B1
- Heading font: Cormorant Garamond
- UI/body font: Manrope

## Design Principles

1. Luxury through simplicity, spacing, typography, and photography.
2. Use charcoal and ivory as the dominant colors.
3. Use champagne gold sparingly as an accent.
4. Avoid excessive gradients, rounded cards, bright colors, and unnecessary effects.
5. Use subtle, smooth animations.
6. Mobile-first responsive design.
7. Keep the interface clean and conversion-focused.
8. Use real product images when provided; do not invent product claims.

## Future Backend

The backend/admin phase will use a database, authentication, storage, product management, inventory, orders, customers, coupons, and reviews.

Do not build the backend prematurely. First complete and validate the frontend UI/UX.

## Quality Standard

Before considering a phase complete:

- No console errors
- No broken links
- No overflow on mobile
- No layout shifts caused by images
- Accessible buttons and forms
- Good keyboard navigation
- Responsive at common screen sizes
- Consistent typography and spacing
- Reusable components
- Clean code
- No unnecessary dependencies or files
